# Portfolio entry point

GitHub Pages forwards visitors to [prateekmulye.dev](https://prateekmulye.dev/), the canonical portfolio.

Publish the `main` branch from `/` (root). This repository requires no build step or dependencies. `index.html` uses a fixed HTML redirect and keeps a visible fallback link for browsers that do not follow it.

Maintain career content in the canonical portfolio instead of duplicating it here.
